# Vox Landing Site

Одностраничный лендинг Vox на чистом HTML/CSS/JS.

## Что внутри
- адаптивная верстка;
- встроенное оптимизированное демо Vox (~2.5 MB вместо исходных ~41 MB);
- sticky navigation;
- анимации появления;
- FAQ accordion;
- рабочие CTA и формы: отправка открывает WhatsApp с заполненным сообщением;
- модальное окно запроса пилота;
- блок безопасности без неподтвержденных compliance-обещаний;
- `vercel.json` для простого деплоя на Vercel.

## Локальный запуск
Откройте `index.html` напрямую или запустите локальный сервер:

```bash
python -m http.server 8080
```

и перейдите на `http://localhost:8080`.
